Total MobilizationUI direction review

Four UI Directions — Pick One Before We Touch index.html

The current chrome (parchment, rubber stamps, grease-pencil rings) is a 1940s paper-map-room pastiche sitting on top of a near-future arsenal — hypersonics, armed drones, cruise/ballistic missiles, NATO battalion symbology, grey-steel vehicles. The designer flagged both problems at once: the UI "feels blatantly AI" (outline soup, one font, uniform spacing — see docs/reference-ui-style.md and docs/reference-ui-typography.md) and the paper skin itself doesn't match what the game is actually about (see docs/reference-ui-strategy-games.md). The four options below render the exact same widget set — a live-looking resource ledger, a reinforcements panel with an affordable row and a disabled/unaffordable row, a two-battalion roster with a healthy and a shaken status, a dispatch line, and buttons in normal / hover / disabled / selected states — so they're a fair side-by-side. Two directions are modern/near-future (①②), one is the existing paper concept done properly (③), one is a fully different brutalist printout language (④).

OPTION 1

Modern Military C2 / Tactical Display

Dark slate command console — thin precise hairline rules (never boxes), cyan data accents with an amber secondary and red alert, condensed uppercase technical labels, tabular monospace for every number. Evokes an actual battle-management console (Command: Modern Operations, WARNO). Matches the game's own grey-steel unit palette and near-future arsenal directly. Tradeoff: dark UI needs contrast discipline to stay legible over a dark map — accent colors are reserved for state (cyan=neutral-ready, amber=caution, red=alert) so they don't turn into noise.

OPTION 2

Clean Operational Minimal

Near-flat, near-monochrome grey UI with a single amber accent, generous whitespace, and hierarchy built from type weight/size rather than boxes or borders — separation comes entirely from tone and space (soft shadows + rounded 8–12px cards used consistently, not the "uniform 2px everywhere" tell). Reads modern and calm — closer to a premium ops dashboard than a game skin. Tradeoff: the most "generic modern app" of the four if not paired with strong iconography and a confident accent color; the icon-led rows here are load-bearing, not decoration.

OPTION 3

Refined War-Room Paper

The existing "paper pinned to a map table" concept, executed to the letter of docs/reference-ui-style.md: the universal 1px outline is gone (grain + shadow define every edge instead), rows separate by tint + a colored left-rule instead of a full border, and labels/values now split sans-serif caps vs. monospace tabular data. Warm, period-appropriate, still legible and dense. Tradeoff — stated up front — this is deliberately a 1940s pastiche sitting next to hypersonics and armed drones; however well it's built, it will always read more "war film" than "modern C2." Best fit only if the fiction ("you're literally a desk officer at a map table") is meant to be foregrounded over the hardware's own modernity.

OPTION 4

Brutalist / Technical Readout

One monospace face, everywhere, no exceptions. High-contrast black-on-off-white, hard 1–2px rules used deliberately as a real ruled table (this is the one direction where "rules everywhere" is correct, not an AI tell — see docs/reference-ui-style.md §3.1 "Option C: Flat + Ruled"), zero corner rounding, a single stamp-red reserved for alerts only. Reads like an actual dot-matrix wargame printout (Command: Modern Operations, Unity of Command). Tradeoff: the least "designed" looking of the four at a glance — its whole appeal is austerity, so it lives or dies on whether the density stays genuinely scannable rather than just stark.
