# WARBANDS DIALOGUE
#
# Everything the bands say over their heads lives in this one file. Edit it with any text editor.
#
#   * A line starting with # is a comment and is ignored. Blank lines are ignored.
#   * [NAME] starts a group. Every line under it, one per row, is one thing a soldier can say; the game picks one at random.
#   * [NAME Something] is a variant of the group for one band type or band style (see the list at the bottom). When the band has one, it is used about half the time.
#   * You can use these in a line: {mate} = the first name of another soldier in the band, {who} = the player's name, {armor} = the armor set the player wears, {n} = a number.
#   * Keep a line to one or two sentences. Run-ons and panic are in the voice, so are very sincere threats.
#   * After editing, rebuild the mod (or ask whoever builds it). If a group is empty or missing the soldiers just stay quiet for that situation.
