# ============================================================================================================
# LEVY SOLDIER DIALOGUE  (designer-editable, no code changes needed)
# ============================================================================================================
# One entry per line:        TRIGGER | Temperament | text
# Blank lines and lines starting with # are ignored. A malformed line is logged with its line number and skipped.
# The table is read when the mod loads and again whenever the game language changes (Dialogue/<culture>.txt,
# falling back to this file).
#
# TEMPERAMENT   Greenhorn, Sellsword, Zealot, Cynic, Veteran or Any.
#               A temperament line is only spoken by soldiers of that temperament. A Veteran line is only spoken by
#               soldiers who earned Veteran. Any is spoken by everyone. Personality lines are picked more often than Any.
#
# TRIGGER       IDLE IDLE_NIGHT NAMEDROP BLOOD_MOON PARTY GRAVEYARD RAIN
#               BIOME_JUNGLE BIOME_DUNGEON BIOME_UNDERWORLD BIOME_SNOW BIOME_CORRUPTION BIOME_CRIMSON BIOME_HALLOW
#               BIOME_OCEAN BIOME_UNDERGROUND
#               PAYDAY UNPAID DESERTED MUSTER STAND_DOWN NO_ONE_LEFT
#               EVENT_GOBLINS EVENT_PIRATES EVENT_ECLIPSE EVENT_PUMPKIN EVENT_FROST EVENT_MARTIANS EVENT_OLDONES EVENT_FROSTLEGION
#               ENGAGE KILL HURT LOW_HP OUT_OF_AMMO HOLD_FIRE
#               BOSS_SIGHTED   (any main boss comes into view; also the fallback when a boss has no lines of its own)
#               BOSS_<name>    (one boss; <name> is the vanilla NPC internal name: KingSlime EyeofCthulhu EaterofWorldsHead
#                               BrainofCthulhu QueenBee Deerclops SkeletronHead WallofFlesh QueenSlimeBoss Retinazer
#                               Spazmatism TheDestroyer SkeletronPrime Plantera Golem HallowBoss DukeFishron CultistBoss
#                               MoonLordCore)
#               COMRADE_HIT COMRADE_DOWN SHAKEN ROUTED RALLIED VICTORY PROMOTED VETERAN DEATH_MESSAGE
#               MUTINY MUTINY_BEGIN MUTINY_REFUSE MUTINY_CALM   (soldiers in revolt over unpaid wages)
#               DRINK   (the army is served a round from a keg, case or cooler; floating lines, a few levies each time)
#               FIRESIDE PASTIME PASTIME_NIGHT   (levies off duty on Free Rein: talk by a campfire or a keg; talk at a kite or a cheer by day; talk under the stars; floating lines to a comrade nearby)
#               TAKEOFF FLIGHT_FEAR LANDING   (a winged levy on a long march: a complaint before take-off, fear in the air, relief on landing; floating lines, a few at a time)
#               OFFICER_MARCH NURSE_MARCH   (officers talking on the march)
#               OFFICER_<Officer>_<STATE>   (an officer's own voice; STATE is IDLE MARCH HOLD FIGHT BOSS HURT VICTORY)
#               OFFICER_CHAT_<STATE>        (the officer voice used when an officer has no lines of his own for that STATE)
#
# WHERE A LINE SHOWS UP
#   Right-click chat:   IDLE IDLE_NIGHT NAMEDROP BLOOD_MOON PARTY GRAVEYARD RAIN BIOME_* PAYDAY UNPAID HOLD_FIRE EVENT_*
#   Emote bubble + a small floating line:   ENGAGE KILL HURT LOW_HP OUT_OF_AMMO SHAKEN COMRADE_HIT MUSTER STAND_DOWN PROMOTED VETERAN
#   Floating line over the head:   BOSS_SIGHTED BOSS_* COMRADE_DOWN ROUTED RALLIED VICTORY (and EVENT_* for the militia)
#   Chat log:   DEATH_MESSAGE DESERTED NO_ONE_LEFT
#   Floating line over the head, in a mutiny:   MUTINY (the cries) MUTINY_BEGIN (the first shout) MUTINY_REFUSE (an order is refused) MUTINY_CALM (back to work once paid)
#   Officers:   OFFICER_MARCH and NURSE_MARCH are floating lines while marching. OFFICER_<Officer>_<STATE> and OFFICER_CHAT_<STATE> are what an officer says when you right-click them.
#   Floating lines appear on a blue chat bar over the speaker's head. The text types itself in, so keep lines short.
#   Militia only ever speak: ENGAGE KILL HURT LOW_HP OUT_OF_AMMO COMRADE_HIT COMRADE_DOWN SHAKEN ROUTED RALLIED MUSTER
#   STAND_DOWN EVENT_* BOSS_SIGHTED BOSS_* DEATH_MESSAGE.
#
# PLACEHOLDERS (a line whose placeholder cannot be filled is skipped, so keep a few lines per trigger without any)
#   {Player}   the commander (or "the boss")           {Name}     the speaking soldier
#   {Comrade}  the comrade who fell or was hit         {Boss}     the boss being fought
#              (only when the game names one; otherwise the line is skipped, never shown with a gap)
#   {Killer}   what killed the soldier                 {Town}     the settlement
#   {Wage}     the soldier's daily wage
#   {Tank} {TankHe} {TankDeaths}        the levy with the most deaths ("he's"/"she's"); only 3 or more, never the speaker
#   {Glutton} {GluttonKills}            the levy with the most kills; only 25 or more, never the speaker
#   A line may start with a [condition]: [summoner] (the speaker is one), [non-summoner] (the speaker is not, and the army has one),
#   [fragile] (most levies have under 200 max HP), [mage] (the speaker is one), [non-mage] (the speaker is not, and the army has one),
#   [hardmode+officer] (hardmode and an officer is commissioned), [goblin] (the Goblin Tinkerer lives here),
#   [lowhp] (the speaker is under 20 HP), [boss] (a boss fight is on or ended within a minute).
#   {WorldName} the world's name           {Officer}  the role of a commissioned officer, e.g. Painter
#   Town NPCs (the line only fires while that NPC lives in the world):
#   {Guide} {Nurse} {ArmsDealer} {Demolitionist} {Merchant} {Dryad} {Clothier} {PartyGirl} {Tavernkeep} {TaxCollector}
#   {Mechanic} {GoblinTinkerer} {Wizard} {Steampunker} {Cyborg} {Pirate} {Truffle} {Stylist} {Angler} {DyeTrader}
#   {Painter} {WitchDoctor} {Golfer} {Zoologist} {Princess} {SantaClaus}
#
# A line is not repeated within two minutes. Keep lines to one or two short sentences. Plain ASCII only.
#
# THE FILE, TOP TO BOTTOM  (every spoken levy and officer line is in this one file; each part is a block of lines sharing a TRIGGER)
#   1. IDLE by temperament, IDLE_NIGHT, NAMEDROP          what a levy says when you right-click it
#   2. Situations and Biomes                              weather, party, blood moon, graveyard, and where you are
#   3. Pay and service                                    payday, unpaid, deserted, muster, stand down, hold fire
#   4. Events                                             invasions and moons
#   5. Combat                                             engage, kill, hurt, low hp, out of ammo
#   6. Bosses                                             boss sighted, then one block per boss
#   7. Comrades and fear                                  comrade hit or down, shaken, routed, rallied, victory, promotions
#   8. Death messages                                     the chat-log line when a levy dies
#   8b. Free Rein pastimes, flying and drinks               FIRESIDE, PASTIME, TAKEOFF, LANDING, DRINK (after the death messages)
#   9. Mutiny                                             the cries of levies revolting over unpaid wages
#  10. Officers on the march                              OFFICER_MARCH and NURSE_MARCH
#  11. Officer chat, generic                              OFFICER_CHAT_<STATE>, used when an officer has no voice of his own
#  12. Officer voices                                     one block per officer, OFFICER_<Officer>_<STATE>
#  13. Staged lines                                       written but commented out until the game has the trigger or tag they need (see the block before the officers)
#
# EDITING WITHOUT REBUILDING THE MOD
#   1. In game (single player, or on the server) type  /levydialogue export  . It copies this file to
#          <Terraria save folder>/tModLoader/Levy/Dialogue/en-US.txt     (/levydialogue path  prints the exact place)
#   2. Edit that copy in any text editor. Add, remove or change lines. Keep the three columns separated by the | character.
#   3. Type  /levydialogue reload  . The edited file is read at once, and also every time the mod loads.
#   While the edited copy exists the mod reads it instead of this file. Delete the copy to go back to this one.
#   To replace an existing copy with the mod's file again use  /levydialogue export force  (the old copy is kept as en-US.txt.bak).
#   A bad line is logged with its line number and skipped, so one typo never silences everyone.
# ============================================================================================================
